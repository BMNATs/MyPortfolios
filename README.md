## 🚀 Key & Featured Projects

### 🌟 1. Eduguide — RAG Education Guidance Chatbot *(Featured Showcase)*
> นวัตกรรมแชทบอทอัจฉริยะวิเคราะห์ความถนัดและเส้นทางการศึกษาที่เหมาะสมด้วยสถาปัตยกรรม RAG

* **Problem:** ข้อมูลหลักสูตรและการศึกษาต่อมีความกระจัดกระจาย ขณะที่ AI Chatbot ทั่วไปมักให้คำแนะนำที่กว้างเกินไปหรือไม่ตรงกับบริบทจริง (Hallucination)
* **Solution:** ออกแบบระบบ Retrieval-Augmented Generation (RAG) ดึงฐานข้อมูลหลักสูตรที่ถูกต้องมารองรับการตอบคำถาม ทำให้ผลลัพธ์มีความแม่นยำและตอบโจทย์ความถนัดของผู้เรียนอย่างแท้จริง
* **Role & Responsibility:** มีส่วนร่วมในการออกแบบ Context Retrieval, พัฒนาและทดสอบ RESTful API Endpoint สำหรับเชื่อมต่อระบบแชท
* **Tech Stack:** Python, RAG Architecture, RESTful API, MySQL, Postman

## 💡 Vibe Coding Insights & Reflection

โปรเจกต์นี้สะท้อนกระบวนการทำงานร่วมกับ AI ภายใต้แนวคิด **Human-in-the-loop**:

1. **Persona & Design Customization:** กำหนด Tone of Voice และ UI Concept ให้เป็นสไตล์ Bento Dark Glam (Deep Mulberry & Fuchsia) เพื่อฉีกกรอบ Portfolio ไอทีแบบเดิมให้ดูโดดเด่นและมีเอกลักษณ์เฉพาะตัว
2. **Context-Driven Prompting:** ควบคุมผลลัพธ์ด้วยการระบุกลุ่มเป้าหมาย (Recruiter), โครงสร้างการเล่าโปรเจกต์ (Problem-Solution-Outcome), และความพร้อมด้าน Responsive 100%
3. **Refinement & Testing:** ตรวจสอบความถูกต้องของสัดส่วน Grid, การทำงานของ Floating Navigation, และป้องกันการฝัง API Keys หรือรหัสผ่านลงในโค้ดอย่างเคร่งครัด
